# odin-recipes

## Introduction

It’s time to practice all of the HTML knowledge you have acquired. In this project, you are going to build a basic recipe website.

The website will consist of a main index page which will have links to a few recipes. The website won’t look very pretty by the time you’ve finished but it’s important to keep in mind that the purpose of this project is to build your HTML chops; we will revisit this project in the future to style it up with CSS.

## What I Learned

### HTML Foundations

- **Structure:** boilerplate, headings, paragraphs, and nested lists
- **Links:** absolute, relative (`./`, `../`), and same-page links, with `target="_blank"` and `rel="noreferrer"` for new tabs
- **Images:** `<img>` with `src`, `alt`, `height`, and `width`
- **Showing code on a page:** escape with `&lt;` `&gt;` `&amp;` and wrap in `<code>` or `<pre>`
- **Git:** `git add`, `git commit`, `git push`, plus `git clone` and `git remote -v`
- **File structure:** lowercase names, no spaces, and `index.html` in the root
